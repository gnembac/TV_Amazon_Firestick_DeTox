# Modern webOS OLED TV (for example LG OLED42C5) with a Fire TV Stick on HDMI

The TV is not Android: no ADB, no package cleanup. What helps:

- Power the stick from its own adapter, not from the TV's USB port (more stable on standby).
- HDMI-CEC (SimpLink) on only if the TV remote should control the stick; switch it off if the TV wakes up by itself or the input jumps.
- A 1080p stick (HD class) outputs 1080p; native 4K/Dolby Vision apps run on the TV's own apps.
- Picture: Filmmaker/Cinema for movies, Game mode only for consoles. Keep OLED pixel protection and logo-luminance dimming on; use the sleep timer.
- If the stick streams everything, switch off the TV's own recommendations/ads and personalised-advertising options in its privacy settings;
  keep the TV online only for firmware updates.
- Restart the stick every few days (Settings > My Fire TV > Restart) and keep storage below about 70 %.
